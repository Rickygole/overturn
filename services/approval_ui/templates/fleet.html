How discovery works here

This page is not a document somebody updates when an agent changes. It calls core.registry.build_catalogue() on every request, and that function reads the same three sources the running fleet reads: identity and purpose from infra/agents.env, the file the IAM setup script uses to create these service accounts; model and output contract from the ADK definitions in agents/adk_fleet.py, the same definitions the pipeline executes; and what each agent may read or write from core.gateway.POLICY, the dict the gateway actually enforces on every datastore call. The service account column is Agent Identity — a distinct account per agent, not one shared credential. The read and write columns are Agent Gateway — the access matrix a security review would ask for, printed rather than described.

A catalogue that is maintained by hand is a catalogue that drifts the moment somebody forgets to update it, and a wrong catalogue about who may touch patient data is worse than no catalogue at all. This one cannot drift: change what an agent reads or writes and the definition_sha256 column changes with it, because it is a hash of the same fields the row shows. There is no separate publishing step to skip.

Tracing

Every agent invocation in this fleet runs inside an OpenTelemetry span, and core/audit.py stamps the trace id and span id onto every audit event it writes — the same events a reader can open on any case page, under its audit trail disclosure. That is what makes an agent's behaviour on one case reconstructable after the fact rather than merely logged.

There is deliberately no Cloud Trace link on this page. Cloud Trace sits behind a Google sign-in and a project a reader here almost certainly cannot see, and a link that returns a permissions error is worse than no link at all — it reads as something hidden rather than something a judge simply is not signed in to view. The trace and span ids are printed instead, on the case pages that carry them, as identifiers a reader can paste into their own tooling rather than a link that fails for everyone but us. The absence is a decision, not a gap.
