3. Run the whole thing yourself

The pipeline ships with a scripted backend that answers every model call deterministically. All eight cases run end to end with no Google Cloud project, no credentials, and no cost — the same agents, the same orchestration, the same grounding checks, only the model responses are canned.

git clone https://github.com/rickygole/overturn
cd overturn
uv sync

# all eight cases, offline and free
uv run python scripts/evaluate.py

# one case, with the full audit trail printed
uv run python scripts/casectl.py run CASE-001 --explain

# the approval queue on localhost
uv run uvicorn services.approval_ui.main:app --port 8080

To point the same run at real Gemini on Vertex AI instead, set two variables. This is exactly how the numbers on the evidence page were produced:

OVERTURN_RUNTIME_MODE=local OVERTURN_LLM_BACKEND=vertex \
    uv run python scripts/evaluate.py --live
The offline and live runs are the same code path. Only the backend is swapped. That is what makes the two scorecards on the evidence page comparable — and it is why the two cases where they disagree are worth reading rather than hiding.
